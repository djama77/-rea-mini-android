# REA Mini Analyzer V3

Application Android d'analyse statique JavaScript/Electron (ZIP, ASAR), avec rapports techniques et institutionnels.

## Installation du code source

Le projet complet est disponible dans l'archive `REA_Mini_Android_V3.zip` fournie dans la conversation ChatGPT. Les fichiers de l'application `www/index.html` et `www/vendor/jszip.min.js` doivent encore être ajoutés à ce dépôt avant compilation.

## APK

Le workflow GitHub Actions construit un APK debug via Capacitor. Une fois tous les fichiers ajoutés, ouvrir **Actions > Construire APK Android > Run workflow**, puis télécharger l'artifact `REA-Mini-Analyzer-APK`.
