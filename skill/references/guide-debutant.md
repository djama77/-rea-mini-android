# Guide débutant
1. Ouvrir l'application.
2. Choisir une archive ZIP ou ASAR de son propre projet.
3. Lire la vue d'ensemble et les rôles Electron.
4. Examiner les alertes et les lignes indiquées.
5. Copier le rapport Markdown, puis le vérifier manuellement.
Le fichier est analysé dans le navigateur. La version actuellement publiée charge JSZip depuis un CDN et nécessite donc Internet au premier chargement.
