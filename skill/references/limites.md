# Limites
Analyse statique heuristique, non exhaustive. Pas d'exécution, pas de décompilation APK, pas de preuve automatique de vulnérabilité. Les imports dynamiques, archives ASAR unpacked, sources minifiées ou obfusquées peuvent ne pas être détectés. La version GitHub utilise la bibliothèque JSZip distante, contrairement à l'objectif V3 hors ligne.
